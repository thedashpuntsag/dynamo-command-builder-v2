# AI agent resources

These files teach AI coding agents how to use `dynamo-craft` in an application.

- [`library-reference.md`](./library-reference.md): consumer API patterns, examples, constraints, and common mistakes.

Give `library-reference.md` to an AI agent when it is adding DynamoDB access to another project. The consuming project's requirements, table schema, installed package version, and TypeScript types remain the source of truth.
